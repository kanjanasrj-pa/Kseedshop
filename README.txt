# SeedShop Website

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `SeedShop_Website` ด้วย Visual Studio Code
3. เปิด `index.html` ด้วย Live Server (แนะนำ) หรือดับเบิลคลิกเปิดในเบราว์เซอร์

## ฟังก์ชัน
- ลูกค้า: สมัครสมาชิก/เข้าสู่ระบบ, ค้นหาและกรองสินค้า, เพิ่มลงตะกร้า, ยืนยันคำสั่งซื้อ, ดูประวัติการสั่งซื้อ, แก้ไขโปรไฟล์, ออกจากระบบ
- ผู้ขาย: สมัครสมาชิก/เข้าสู่ระบบในบทบาทผู้ขาย, เพิ่มสินค้า, อัปโหลดรูปจากเครื่อง, แก้ไขสินค้า, ลบสินค้า, จัดการราคาและสต็อก
- บันทึกข้อมูลด้วย localStorage และ sessionStorage ในเบราว์เซอร์

## ข้อจำกัดสำคัญ
เวอร์ชันนี้เป็น Prototype ที่ใช้งานทดสอบได้บนเบราว์เซอร์เครื่องเดียว ข้อมูลยังไม่ได้แชร์ข้ามเครื่องหรือผู้ใช้จริง และระบบเข้าสู่ระบบยังไม่ปลอดภัยสำหรับการใช้งานจริง เพราะยังไม่มี Backend/ฐานข้อมูล/ระบบเข้ารหัสรหัสผ่าน/ชำระเงินออนไลน์ หากจะเปิดร้านใช้งานจริงควรต่อ Backend และฐานข้อมูล เช่น Supabase หรือ Firebase พร้อมระบบยืนยันตัวตนและจัดเก็บรูปภาพบน Cloud Storage
